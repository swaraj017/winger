# winger.ai 

### Your AI Wingman for Modern Dating.

winger.ai is an AI-powered dating coach that helps users improve replies, dating profiles, confidence, and conversations using modern AI.

Built with a futuristic cyberpunk-inspired UI, winger.ai analyzes chats, selfies, bios, and texting style to generate smarter replies and better first impressions.

* 💬 AI Chat Reply Generator

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/swaraj017/winger.git
```

Go to the project folder:

```bash
cd winger
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
